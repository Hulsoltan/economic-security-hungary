# Економічна безпека Угорщини — навчальний вебсайт

Готовий адаптивний сайт для публікації через GitHub Pages. Складається з трьох взаємопов'язаних HTML-сторінок:

- `index.html` — головна сторінка, авторка та навчальна інформація.
- `country.html` — аналіз Угорщини, інтерактивні графіки, таблиця, загрози й зіставлення з орієнтирами.
- `insights.html` — висновки, прогнози та офіційні першоджерела.

Спільні `style.css` (адаптивний дизайн), `script.js` (мобільне меню та перемикання графіків), `assets/` (власна ілюстрація і значок сайту).

## Як перевірити сайт

Розпакуйте ZIP-архів, а тоді відкрийте файл `index.html` у браузері. Перевірте навігацію, три сторінки, кнопки графіка, відображення на телефоні або через режим мобільного пристрою в інструментах розробника. Для шрифтів з Google Fonts потрібен інтернет; без нього використовуються системні шрифти. Графіки та авторська ілюстрація не потребують інтернету.

## Публікація в GitHub Pages

1. Увійдіть на https://github.com і створіть **Public** репозиторій, наприклад `economic-security-hungary`.
2. У репозиторії оберіть **Add file → Upload files**.
3. **Розпакуйте ZIP**, а потім перетягніть **вміст** цієї папки, щоб `index.html`, `country.html`, `insights.html`, `style.css`, `script.js` та папка `assets` опинилися в корені репозиторію (не у вкладеній папці). Збережіть через **Commit changes**.
4. Відкрийте **Settings → Pages → Build and deployment**.
5. У **Source** виберіть **Deploy from a branch**, у **Branch** виберіть `main` і `/(root)`, натисніть **Save**.
6. Дочекайтеся повідомлення про розгортання. Сайт матиме адресу на кшталт `https://ВАШ_ЛОГІН.github.io/economic-security-hungary/` — точна адреса з'явиться в Settings → Pages.
7. Відкрийте посилання на сайт у приватному вікні, перевірте всі три сторінки та графіки.
8. Викладачеві надайте **два посилання**: адресу сайту й адресу публічного репозиторію.

**Важливо:** автоматично опублікувати сайт у вашому GitHub неможливо без доступу до вашого облікового запису. Цей архів містить готові файли, а не опублікований сайт.
